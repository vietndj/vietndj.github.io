Cách Lấy API Key CetriX

Mở CetriX Keys ↗

Bạn chỉ cần làm theo 2 bước cực nhanh:

  1. Truy cập thẳng vào link: https://cetrix.app/chat/hub/keys (nếu chưa đăng nhập, trang web sẽ tự chuyển hướng để bạn đăng nhập tài khoản đã mua gói).
  2. Tại mục Your API keys, bấm nút Reveal 👁️ cạnh dòng cetrix-agent-default để hiện key đầy đủ.
  3. Bấm Copy chuỗi key bắt đầu bằng sk-... rồi dán thẳng vào khung chat Antigravity cho AI là xong!
💡 Rất tiện lợi: Khi bạn dán key vào khung chat, Antigravity sẽ tự động phát hiện và lưu vào file cấu hình bảo mật trên máy bạn, bạn không cần phải tự thao tác file nào cả!
