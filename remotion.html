1. Bản chất & Triết lý hoạt động của Remotion

Remotion là một framework mã nguồn mở cho phép biến mã nguồn React, TypeScript, HTML, CSS và Canvas/SVG thành video MP4 chất lượng cao.

Nguyên lý cốt lõi: Mỗi video là một React Component. Mỗi khung hình (frame) là một trạng thái render xác định của DOM:
Visual State = f(currentFrame)

B. Hàm nội suy toán học interpolate()

Biến đổi mượt mà giữa các khoảng frame thành giá trị hiển thị (opacity, scale, vị trí):

TypeScript (TSX) 
import { interpolate } from "remotion";

// Khi frame từ 0 -> 15: opacity tăng từ 0 -> 1
// Khi frame từ 140 -> 156: opacity giảm từ 1 -> 0
const opacity = interpolate(
  frame,
  [0, 15, 140, 156],
  [0, 1, 1, 0],
  { extrapolateLeft: "clamp", extrapolateRight: "clamp" }
);

C. Chuyển động vật lý spring()

Tạo hiệu ứng nảy tự nhiên như giao diện iOS/SaaS cao cấp:

TypeScript (TSX) 
import { spring, useCurrentFrame, useVideoConfig } from "remotion";

const frame = useCurrentFrame();
const { fps } = useVideoConfig();

const scale = spring({
  frame,
  fps,
  config: { damping: 14, mass: 0.6, stiffness: 120 },
});

7. Các Lệnh CLI Render Thiết Yếu

CLI Commands 
# 1. Bật giao diện xem trước Studio (Preview Player)
npx remotion preview

# 2. Render video hoàn chỉnh đa luồng
npx remotion render FullVideoWithBroll out/final.mp4 --concurrency=4

# 3. Render lớp Overlay nền trong suốt (Alpha ProRes 4444)
npx remotion render MotionGraphicsOverlayOnly out/overlay.mov --codec=prores --prores-profile=4444

# 4. Render 1 frame ảnh tĩnh kiểm tra
npx remotion still FullVideoWithBroll out/preview_frame.png --frame=75

8. Quy Tắc Vàng Cho AI Agent Khi Viết Code

  • Luôn chặn biên interpolate: Thêm { extrapolateLeft: "clamp", extrapolateRight: "clamp" } vào mọi hàm nội suy.
  • Giải phóng DOM khi ngoài phạm vi: Đặt if (frame < start || frame > end) return null; ở đầu mỗi component.
  • Sử dụng vật lý lò xo (Spring): Luôn ưu tiên spring() cho hiệu ứng xuất hiện thay vì CSS keyframe tuyến tính.
  • Tách nhỏ từng Scene: Mỗi phân cảnh tạo một file .tsx độc lập trong src/components/ để dễ bảo trì.
